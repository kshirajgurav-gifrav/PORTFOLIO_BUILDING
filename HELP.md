# Line Editor Help Guide

## 1. insert
Adds a new line of text at the specified line number, shifting existing lines down.
* **Syntax:** `insert <line_number>`
* **Example:** 
  `> insert 1`
  `Enter text: Hello World`

## 2. delete
Removes the line at the specified number, shifting the lines below it up.
* **Syntax:** `delete <line_number>`
* **Example:** 
  `> delete 1`

## 3. display
Prints all current lines in the document alongside their line numbers.
* **Syntax:** `display`
* **Example:** 
  `> display`

## 4. help
Shows a quick reference list of all available commands.
* **Syntax:** `help`
* **Example:** 
  `> help`

## 5. exit
Closes the simple line editor.
* **Syntax:** `exit`
* **Example:** 
  `> exit`
